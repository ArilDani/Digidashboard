# Digidashboard HIMA BISDIG FEB UNM

Digidashboard adalah platform visualisasi data analitik dan monitoring kegiatan yang dirancang khusus untuk Himpunan Mahasiswa Bisnis Digital (HIMA BISDIG) FEB UNM. Aplikasi ini bertujuan untuk mempermudah pemantauan performa program kerja (proker) dan agenda secara real-time, memberikan insight berbasis data, serta menampilkan feedback kepuasan dari peserta kegiatan.

## 🚀 Fitur Utama

- **KPI Cards & Analytics**: Menampilkan metrik utama seperti total peserta, rata-rata nilai pre-test & post-test, peningkatan nilai (gain), serta rating kepuasan peserta.
- **Visualisasi Data Interaktif**: 
  - *Bar Charts* untuk distribusi nilai pre-test & post-test serta feedback bar.
  - *Donut Charts* untuk persentase peningkatan nilai dan distribusi kepuasan.
  - *Radar Charts* untuk detail kepuasan peserta per aspek kegiatan.
  - *Line Charts* untuk tren performa dan tren rating dari waktu ke waktu.
- **Export Data**: Kemudahan untuk mengekspor laporan data dashboard ke dalam format PDF dan juga format Excel (Spreadsheet).
- **Automated Insights**: Panel wawasan cerdas yang memberikan rangkuman berbasis data terkait performa kegiatan secara otomatis.
- **Ringkasan Keseluruhan (Summary)**: Tabel dan grafik komprehensif untuk membandingkan performa semua kegiatan (proker/agenda) yang ada.
- **Desain Modern & Responsif**: Menggunakan glassmorphism dan tema gelap elegan (dark mode) dengan animasi yang mulus untuk UI/UX premium.

## 🛠️ Tools & Teknologi yang Digunakan

Proyek ini dibangun menggunakan ekosistem teknologi frontend modern yang dioptimalkan untuk performa dan interaktivitas:

- **React (v19)**: Library antarmuka pengguna (UI) berbasis komponen yang interaktif.
- **Vite**: Build tool modern yang memberikan waktu *start* server yang sangat cepat untuk pengalaman *development* maksimal.
- **Tailwind CSS**: Framework CSS berbasis utilitas untuk pembuatan *styling* kustom secara cepat dan responsif.
- **Recharts**: Library *charting* (visualisasi data) ringan dan modular berbasis komponen React.
- **Lucide React**: Koleksi ikon minimalis dan modern berbasis SVG.
- **jsPDF & jsPDF-AutoTable**: Digunakan untuk meng-generate dan mengekspor dokumen laporan ke format PDF.
- **XLSX (SheetJS)**: Memungkinkan pemrosesan data ke format Spreadsheet (Excel) untuk keperluan pelaporan eksternal.
- **Oxlint**: Linter yang super cepat untuk memastikan kualitas kode JavaScript dan React.

## 🎯 Tujuan Pembuatan Dashboard

Dashboard ini secara spesifik diciptakan untuk:
1. **Digitalisasi Pelaporan**: Membuat laporan berbasis digital
2. **Evaluasi Berbasis Data**: Membantu jajaran pengurus HIMA BISDIG FEB UNM dalam mengevaluasi persentase keberhasilan setiap kegiatan berdasarkan hasil objektif pre-test & post-test, serta feedback kepuasan langsung dari peserta.
3. **Transparansi & Monitoring Terpusat**: Memantau perkembangan seluruh program kerja melalui satu layar, memudahkan koordinasi antar panitia/pengurus, serta dapat difungsikan sebagai bukti portofolio kepengurusan secara profesional.
